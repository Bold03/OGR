OAFISH GRASS LIBRARY
====================

Install this entire folder as:

X-Plane 11\Custom Scenery\OafishGrass_Library\

The library exports this WED resource:

OafishGrass/ogr_grass.for

With OGR v0.3.0+, airport scenery no longer needs its own copy of the grass
OBJ/texture files. Draw Forest Area polygons in WED using the virtual resource,
Save + Export Scenery Pack, and the OGR plugin reads those DSF polygons.

Keep OafishGrass_Library enabled in scenery_packs.ini.
