OAFISH GRASS RUNTIME v0.2.0 - START HERE
========================================

1) BUILD/DOWNLOAD the plugin from GitHub Releases.

2) INSTALL:
   X-Plane 11\Resources\plugins\OafishGrassRuntime\win_x64\OafishGrassRuntime.xpl

3) COPY this folder into your scenery:
   release\WED-Starter\OafishGrass

   Example:
   X-Plane 11\Custom Scenery\WIDN Tanjung Pinang\OafishGrass\ogr_grass.for

4) IN WED:
   - Choose Forest Tool
   - Resource: OafishGrass/ogr_grass.for
   - Draw the grass polygon exactly where grass is allowed
   - Holes are supported
   - Set WED Density as desired
   - Save and Export Scenery Pack

5) START X-PLANE.
   OGR v0.2 reads the exported uncompressed WED DSF automatically.
   BUILD_GRASS_AREAS.cmd is NOT required for the normal workflow.

6) AFTER EDITING WED:
   - Save and Export Scenery Pack again
   - Then restart X-Plane, or use:
     Plugins > Oafish Grass Runtime > Reload WED/DSF grass areas

7) FALLBACK ONLY:
   If Log.txt says the DSF is compressed/unsupported, run:
   OafishGrass\BUILD_GRASS_AREAS.cmd
   OGR preserves the legacy ogr_areas.json when direct DSF parsing cannot be used.

8) REPLAY:
   - Fly/taxi normally first so OGR records history
   - Prop RPM / jet power / weather wind are recorded at 20 Hz
   - Enter X-Plane Replay and scrub inside the recorded window
   - Grass uses recorded prop wash / jet blast / wind
   - History window is up to about 20 minutes

DEFAULTS:
- Draw/OBJ LOD: 914.4 m = 3000 ft
- Animated ring: 600 m
- Boundary safety margin: 1.4 m
- Weather wind: ON
- Prop RPM/thrust wash: ON
- Jet N1/thrust wash: ON
- Replay-aware engine/wind history: ON
- Max active grass: 1600
- No shadow / no black grass cards retained

IMPORTANT:
The .for file is used for WED authoring and OGR metadata. OGR reads Area forest
polygons from the exported DSF and draws the real grass. SSA is not required.
